# 01 - Devcontainer Basics

This section introduces the core concepts behind Devcontainers and how they simplify onboarding for software projects.

## Goals

- Understand what a devcontainer is and why it is useful
- Learn how a container-based development environment is defined
- Explore the relationship between VS Code, Docker, and devcontainer configuration

## Suggested activities

1. Review the devcontainer configuration files in the repository.
2. Open the project in VS Code using the recommended workflow.
3. Observe how the environment is built and exposed to the editor.
4. Compare the containerized workflow with a local setup.

## Expected outcome

You should be able to explain the purpose of a devcontainer and use one to start a consistent development environment.
