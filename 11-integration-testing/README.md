# 07 - Integration Testing

This section covers techniques for testing systems that depend on external services, hardware abstractions, or distributed components.

## Goals

- Understand the value of integration testing in embedded and distributed systems
- Learn how container-based tools can support realistic test environments
- Explore patterns for isolating dependencies during tests

## Suggested activities

1. Review the key principles with the instructor.
2. Test out the Testcontainers Native demo in [cpp-project](./cpp-project/).

## Expected outcome

You should have a practical understanding of how integration testing can be made more reliable with containerized infrastructure.
